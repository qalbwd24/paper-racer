# 纸上赛车游戏

独立编写的单人及最优人机原型 v0.2，2026-09-10。没有引用前面调研的赛车项目代码。采用原生 HTML、CSS、JavaScript 和 SVG，运行不需要安装游戏引擎、下载依赖或联网。

## 开始玩

双击本目录的 **开始游戏.cmd**。也可以进入 dist 文件夹，双击 **index.html**，用 Edge 或 Chrome 打开。

先点绿色起跑线上的圆点，再点击棋盘上的候选落点或右侧九宫格。中心键表示保持速度，不是停车。方向按钮调整的是速度，图上候选点显示的才是实际落点。

- 3 张预设赛道：河湾、练习场、折返。
- 起点自由选格点、初速度为零、惯性九选一。
- 途中撞墙、擦角或向起点后方越界，立即失败。车辆按无体积点判断。
- 正向跨过紫色终点即完成。若同一步先到终点再碰到其他边界，按先发生的事件处理；同时碰终点端点和墙算撞墙。
- 不限制思考时间，以完整回合数计分。允许停车、倒退、与自己的旧轨迹交叉。
- 显示风险开关、悬停路线预览、回合轨迹、重开和撤销。危险动作仍可选择。
- 撤销后本局为练习，不更新最佳成绩。
- 自定义赛道：点击连线或按住拖画中心路线，设置宽度，然后开始试跑。第一版不支持分别绘制两侧边界。道路自交、过窄转弯和越出画布会给出提示。
- 导出和导入 JSON 赛道文件。会尝试在当前浏览器保存最后一条自定义赛道及各赛道最佳成绩；浏览器清理数据、更换浏览器、切换本地文件/预览地址，记录可能不同。需要长期保留的赛道请导出文件。

快捷键：数字小键盘 1–9 对应九宫格，5 保持速度；R 重开；Ctrl+Z 撤销。操作输入框或菜单时不会拦截快捷键。

## 文件结构

- dist/index.html：游戏入口。
- dist/style.css：界面样式。
- dist/rules.js：独立规则和赛道几何。
- dist/game.js：玩家操作、显示、编辑、存储。
- dist/solver.js：严格按回合层次搜索的最优路线求解器。
- dist/ai.js：幽灵车、路线显示、求解进度和播放控制。
- check-solver.cjs、check-ai-ui.cjs：最优性与人机控制检查。
- check.cjs：规则、资源和预设赛道可达性检查。
- checks/example-routes.json：早期自动检查找到的示例路线，仅供验证，不声称最优。
- checks/optimal-routes.json：严格求解的预设赛道最优路线及检查结果。
- preview.cjs：可选本地预览服务器，端口 18743，只监听 127.0.0.1；直接双击 HTML 不依赖这个服务器。
- 调研与制作建议.md：前期讨论资料，不是本次代码的来源。

## 当前边界

暂未加入多人、车车碰撞、闭环圈赛。人机以幽灵模式运行，不阻挡你的车。自定义赛道可以手动点击“计算最佳路线”检查可达性；复杂赛道达到计算上限时会明确显示尚未证明，不会把近似路线称作最佳。

## 最优人机怎么用

在右侧“最优人机”里，选择“所有起点 · 全局最佳”或先发车再选择“我的起点 · 同点比较”，点击“计算最佳路线”。绿色虚线是最优路线，绿色方块是人机。

- 你每走一回合，幽灵车按最优路线前进一步。
- 点击“播放人机”可以单独观看，每半秒推进一回合，可暂停或重新播放。
- 可关闭“显示最佳路线”，只保留幽灵车。
- 人机不替你移动，也不更新个人最佳成绩。
- 默认三张赛道的最少回合数：河湾 15、练习场 15、折返 16（在所有发车点之间取最少）。

这里的“最佳”严格指完整回合数最少，不要求同回合路线的长度最短，也不细分最后一回合的过线时刻；存在多条同样最优的路线时显示其中一条。

算法是多起点广度优先搜索：状态为位置和速度，每个动作耗费一回合。依次搜索第 1、2、3……回合的全部可达状态，首次发现完赛路线就证明不存在更少回合的路线。同一状态只保留首次到达。碰撞与终点判定使用玩家相同的规则，无启发式剪枝或人为速度上限。最多发现 500000 个状态；触及限制或取消时，不声称已经找到最优。计算分批进行，避免长时间占住界面。

“我的起点”指本局最初的发车点，不是从目前位置继续规划；计算中途仍可驾驶，完成后幽灵车会同步到你当前的回合。

## 开发检查

本机安装 Node.js 时，在此目录运行 `node check.cjs`、`node check-solver.cjs`、`node check-ai-ui.cjs`。这是开发检查，不是游玩前置步骤。

已检查初始九选一、惯性、刹停与倒退、擦墙、穿墙、起点越界、终点事件顺序、无效赛道及本地资源引用。三张预设赛道均找到无碰撞完赛路线。还在实际浏览器中经游戏操作接口验证了一局河湾完赛、撞墙失败、无效输入不改变状态，以及自定义直线赛道创建和完赛。

普通浏览器不需要游戏的可选 WebMCP 接口；不支持时自动跳过。该接口可让兼容的助手按同一规则启动比赛、选动作、读取状态或创建自定义赛道。

v0.2 新增检查已通过：三张赛道最优路线逐步回放、短直线赛道独立穷举对照、所有起点与逐起点搜索对照、资源限制、取消、无效输入，以及模拟 DOM 中的人机跟随、暂停、撤销、重开、换赛道作废旧结果和不写入个人纪录。此次浏览器控制连接不可用，未完成 v0.2 的实际浏览器操作和视觉复验；模拟 DOM 检查不等同于浏览器验收。
