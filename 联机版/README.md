# 纸上赛车 · 异步联机版

V1 离散和 V2 连续分别保留，原离线版与同步版备份也保留。完整规则、权限、迁移与部署见 [异步更新说明](异步更新说明.md)。

双击 `启动联机.cmd`，打开 http://127.0.0.1:18745/racer/ 。先选赛道或画线，再创建房间；朋友打开邀请链接后点击加入。服务器仅依赖 Node.js 22+，不需要 npm install。局域网可用 `./启动联机.ps1 -Lan`，用窗口打印的局域网地址，不把 localhost 发给朋友。

- 两人选好起点后各自连续走，服务器只向你发送对手到你当前步数为止的轨迹。对手卡片的步数是「当前可见」，不是其最新真实进度。
- 每人每局可悔一步一次，包括刚撞墙或冲线的一步；确认成绩后锁定。双方确认后按完赛步数结算，结束前不会提前公布对手超前成绩。
- 离开会释放座位并重置当前局，房间码保留，其他整组玩家可以再次使用。关网页或断线保留席位；刷新原标签可重连。
- 两人都在房间时，任何阶段都可点「再来一局」。对手收到弹窗，只有同意才清空本局并恢复悔棋次数；拒绝、撤回或 60 秒超时都保留原局，也可稍后处理。
- 撞墙并确认成绩后，可看对手全部已走轨迹及后续更新；确认前仍按自己的步数裁剪。冲线确认不改变原可见规则。
- 房主从「我的房间」管理自己的房间，释放座位、重置或解散；游戏右上角有「管理员登录」。管理员后端默认关闭，本地未配置时显示原因说明；云端配置代理认证后由浏览器弹出登录框。
- V2 联机预览按动画帧处理鼠标移动，复用预览节点和未变化的棋盘，减少重复撞墙计算及轮询重画；点击使用当下位置。原离线 V1/V2 文件保留。
- 24 小时没有房间操作后过期；心跳不续期。空房也可重复使用，但不是永不过期。

席位凭据存在标签 sessionStorage，房主身份存在浏览器 localStorage；同一浏览器多个标签共享房主权限，但席位独立。清除会话或换设备可能失去原身份。

默认服务监听 127.0.0.1:18745；云端使用 127.0.0.1:3211，经已有 Caddy 的 `/racer/` 转发，共用 HTTPS 443，无需新开公网端口。房间文件默认为 `data/rooms.json` 或 DATA_FILE，含身份凭据，不打包、不公开。同步原子写入，保存失败回滚内存；仅支持单进程读写。

开发检查 `node --test test.cjs preview.test.cjs lobby.test.cjs`：22 组测试。运行 `node build.cjs` 产生包含运行文件、测试、哈希及交接说明的独立目录；不包含真实或测试房间数据。原 `部署交接.md` 说明基本环境，最新规则及管理员配置以 `异步更新说明.md` 为准。

当前为本地完成、交付待上线；不把本地浏览器测试或 Caddy 的 401 误写成新版已部署。

本次新增统一大厅 /games/ 和 V1/V2 初始页面房间卡片，详见云游戏服务器/游戏大厅/部署交接.md。安装完整大厅包时同时更新本服务；大厅列表接口 /racer/api/lobby?version=v1（或 v2）不包含轨迹或凭据。
