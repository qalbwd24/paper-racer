# 纸上赛车 V2：连续驾驶

V2 独立于 V1。双击本目录“开始游戏.cmd”或上级目录“启动V2.cmd”。所有资源在 dist，支持直接打开 HTML 离线游玩。

在绿色起跑线上任选位置发车，初始静止。每回合把上次位移原样延长，以延伸终点为圆心，在半径 1 的圆内任选下一落点。圆心保持速度；圆周用满调整幅度。位置和速度允许小数，不吸附网格。限制的是速度改变量的长度，不是车速。

新速度 = 旧速度 + (ax, ay)，ax² + ay² ≤ 1。
新位置 = 旧位置 + 新速度。

直接点击赛道蓝圆选点，或用右侧放大的操纵圆盘。悬停预览，点击落子；“保持速度”选圆心，“确认当前选点”执行预览。小键盘方向键按单位长度调整速度，对角方向归一化；5 保持速度，R 重开，Ctrl+Z 撤销。途中碰墙、擦角、倒退越过起点、终点和撤销练习的规则沿用 V1。

画路线也不再吸附网格，可自由确定起点线方向。道路边界由中心路线及宽度生成。长期保留赛道请导出 JSON；V2 与 V1 的成绩及自定义赛道使用不同存储键。

## 连续人机

点击“计算人机路线”。这是近似搜索，不声称最少回合。可采样 9 个发车点，或从本局最初选择的任意发车位置搜索。不是从车辆当前中途位置规划。

人机圆内采样 49 个加速度，每回合最多保留 3000 个状态，最多搜索 80 回合。筛选时的量化不改变实际坐标，路线逐段使用和玩家相同的碰撞判定。没找到路线不表示无解。人机可独立播放，也随玩家回合前进，不替玩家操作、不修改个人成绩。

## 检查与限制

开发检查：`node check-v2.cjs`、`node check-search.cjs` 和 `node check-ai-ui.cjs`。不属于游玩前置步骤。

已检查圆形限制、浮点位置、惯性、停车、穿墙、过线顺序和自定义起点线。三张预设赛道的人机可行路线为河湾 19、练习场 16、折返 18 回合，不是最优性结论。控制层已通过模拟 DOM 中的跟随、暂停、撤销、重开和换赛道作废旧结果检查。

此次浏览器控制连接不可用，未完成 V2 真实鼠标操作和视觉复验；程序检查不等同于浏览器验收。

preview.cjs 为可选开发预览，只监听 127.0.0.1:18744，与 V1 的 18743 分开。离线入口不依赖 Node.js 或预览服务器。完整版本和算法说明见上级“版本说明.md”。

## 搜索过程与圈外点击

圈外悬停或点击会把鼠标位置沿「惯性圆心 → 鼠标」方向投影到圆周。圈内保留任意落点；圆心保持速度。投影不会规避碰墙，红色风险提示仍然有效。

棋盘下方的「显示搜索过程」展示最近 160 个实际尝试的移动片段：蓝灰线是候选，红线是撞墙淘汰，紫线是当前优先路线。不是全部搜索树，也不是最优性证明。计数覆盖全部尝试，重复尝试也计入；回合结束时保留一帧，计算后可以拖动或回放。慢速计算演示在每轮结束增加 180 毫秒，搜索结果不受展示开关影响。更换赛道或发车范围会清空旧过程。
